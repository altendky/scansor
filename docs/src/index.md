# Scansor Documentation

Scansor is a concept-stage reusable product for constrained parametric geometric
model fitting against scan observations. Users declare the model and
correspondence; Scansor fits only the declared free parameters and returns
diagnostics, auditable parameters, and CAD output.

## Status

**Concept stage.** No product implementation or supported release exists. One
internal, provisional CLI fixture performs bounded local PLY inspection and
read-only replay. A synthetic-only successor exposes the fixed
`stepped-rotational-v0` mapping and NumPy execution-run pipeline without defining
physical validation or automated quality acceptance. Its commands and formats
are non-public. The documented product boundary is current; the architecture and
decisions identified as provisional remain subject to experiments.
